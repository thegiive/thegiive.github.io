# UMT 昇達科技 AI 轉型 Phase 1 每週 Schedule（1-4月）

## 第一階段目標：快速勝利

**核心任務：**
- 現況診斷與轉型建議報告
- 導入 2 個 POC Agent（POC Agent 1：會議記錄工具、POC Agent 2：暫定指導文件生成器）
- 每月 1 場基礎 AI 工作坊（共 4 場）

**服務時數：**
- 每月 16 小時（單數週現場、雙數週線上，各 2h/週）
- 每月 1 場工作坊（3 小時，現場）

**服務模式：**
- 單數週（Week 1, 3, 5, 7, 9, 11, 13, 15）：現場服務
- 雙數週（Week 2, 4, 6, 8, 10, 12, 14, 16）：線上服務
- 工作坊（Week 3, 7, 11, 15）：現場

---

## 第一個月：快速診斷與 POC Agent 1 導入（Week 1-4）

### Week 1：專案啟動與快速診斷（現場）
**現場服務（2h）：**
- 啟動會議（Kick-off Meeting）
- 專案目標與期望對齊
- 關鍵利害人快速訪談（高階主管 2-3 位）
- **POC Agent 1（會議記錄工具）初步需求確認**

**交付成果：**
- 專案啟動簡報
- POC Agent 1 初步需求清單

---

### Week 2：深度訪談與 POC Agent 1 選型確認（線上）
**線上服務（2h）：**
- 快速診斷框架準備
- POC Agent 1 工具評估與比較（Argon / Fireflies / Otter.ai）
- 選型建議報告撰寫
- 使用手冊初稿撰寫

**交付成果：**
- POC Agent 1 工具選型建議
- 快速診斷報告初稿
- 使用手冊初稿

---

### Week 3：第一場工作坊與 POC Agent 1 導入準備（現場）
**現場服務（2h）：**
- 部門主管深度訪談（研發、生產、業務、行政）
- 快速診斷結果簡報
- **POC Agent 1 選型確認與導入計畫討論**
- **POC Agent 1 安裝與設定（開始）**
- 種子用戶名單確認

**工作坊 1（3h，現場）：AI 工具基礎與 Excel 數據分析**
- AI 基本概念與原理
- ChatGPT 在 Excel 中的應用
- 實作：生產數據分析

**交付成果：**
- 快速診斷報告
- POC Agent 1 導入計畫
- 工作坊教材與錄影
- POC Agent 1 測試環境就緒

### Week 4：POC Agent 1 正式上線（線上）

- 線上技術支援與問題解答

## 💡 成功關鍵因素

1. **高層支持**：確保專案啟動會議有高階主管參與
2. **種子用戶選擇**：選擇開放心態、願意嘗試的員工
3. **快速反饋**：每週收集使用反饋，快速優化
4. **實際場景**：POC Agent必須解決真實痛點
5. **文化建立**：透過工作坊建立 AI 學習氛圍

## 📞 溝通機制

### 定期服務
- **單數週（現場）：** Week 1, 3, 5, 7, 9, 11, 13, 15
  - 現場訪談、培訓、問題解決、成果驗證
  - 每次 2 小時
- **雙數週（線上）：** Week 2, 4, 6, 8, 10, 12, 14, 16
  - 線上技術支援、文件撰寫、數據分析
  - 每次 2 小時
- **工作坊（現場）：** Week 3, 7, 11, 14
  - 每場 3 小時
  - 包含理論、示範、實作

### 即時溝通
- **Slack/Teams 群組：** 日常問題討論與技術支援
- **緊急聯絡：** 技術問題 24 小時內回應
- **線上會議：** 雙數週線上服務時段

### 文件管理
- **Google Drive / SharePoint：** 所有文件集中管理
- **版本控制：** 所有報告與手冊版本化管理
- **週報更新：** 每週服務後更新進度

---

**備註：**
- 本 schedule 可根據實際進度彈性調整
- 服務時數可跨週/跨月累積使用
- 工作坊時間可根據企業行事曆調整
- 現場/線上模式可依實際需求協調調整
