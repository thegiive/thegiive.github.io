隱私權政策

1. 管理者與適用範圍

管理者為 Wisely Chen，聯絡信箱為 thegiive@gmail.com。此整合供管理者自己的個人與工作帳號使用。本政策說明此整合如何處理 Google 資料；不代表 Google、OpenClaw 上游專案或本網站其他服務的隱私政策。

2. 存取的資料

依各帳號授予的權限，應用程式可能存取帳號電子郵件地址與基本識別資料、Gmail 郵件內容與附件及標籤／設定、Calendar 活動內容與參與者資訊、Drive 檔案內容與中繼資料，以及 Sheets 試算表內容。OAuth 憑證用於持續存取，不需要將 Google 密碼提供給 gog。

3. 使用目的

Google 資料用於使用者要求的搜尋、摘要、郵件整理、行程管理與同步、文件處理，以及任務清單更新等功能。修改、傳送、分享或刪除資料的操作受 Google 授權範圍及使用者指示或自動化設定限制。

Google 使用者資料及其衍生內容不得用於出售資料、廣告投放、資料仲介、信用評分，或訓練通用人工智慧／機器學習模型。

4. AI 處理與資料分享

gog 從 Google 取得的結果可能進入 OpenClaw。為完成摘要、分析或其他使用者要求的功能，相關內容可能傳送給管理者選用的 AI 服務；通知、同步或分享功能也可能把內容送至管理者指定的通訊服務、收件者或儲存位置。因此，本整合並非承諾所有資料只在本機處理。

資料傳輸僅限提供經使用者同意的功能、安全處理或法律要求。管理者必須選用符合 Google 使用者資料限制的處理方式。除使用者明確同意、安全調查或法律要求外，不允許其他人閱讀這些 Google 資料。

5. 儲存與保護

OAuth refresh token 存放於管理者電腦上 gog 的加密憑證儲存區。讀取結果、附件、產出文件或摘要可能保存於 OpenClaw 的工作目錄、對話與操作紀錄，以及管理者設定的同步或備份位置。對 Google API 的連線使用 HTTPS；本說明網頁不收集 Google 登入密碼、授權碼或 token。

第三方 AI、通訊與儲存服務可能依所選方案和帳號設定保留其收到的資料，管理者須依此限制傳送內容並設定資料保護。

6. 保存、撤銷與刪除

憑證保存至移除、撤銷或失效為止。下載內容、工作產出、對話紀錄與備份依管理者設定及實際工作需要保存；本整合未承諾統一的自動刪除期限。

可前往 Google 帳戶的第三方連線設定撤銷 OpenClaw gog 存取權，以停止後續 API 存取。撤銷不會自動刪除先前下載的檔案、對話、摘要、已傳送內容或備份。要刪除這些副本，請聯絡管理者，並在相關 AI、通訊或儲存服務中另行處理。

7. Google Limited Use

OpenClaw gog 對從 Google API 取得資訊的使用及向其他應用程式的傳輸，將遵守 Google API Services User Data Policy，包括其中的 Limited Use 要求。

8. 政策變更與聯絡

若存取資料種類、使用目的或分享方式有重大變更，管理者應先更新本政策，並在需要時重新取得同意。資料與授權問題請寄信至 thegiive@gmail.com。
