# 超慢跑也能 Coding：Claude Code 帶來的真正生產力

[ ![Wisely Chen](/content/images/size/w160/2025/09/6672228-F20250919----02-----------SN------10945w-1.jpg) ](/author/wisely/)

#### [Wisely Chen](/author/wisely/)

28 Oct 2025 — 5 min read

![超慢跑也能 Coding：Claude Code 帶來的真正生產力](/content/images/size/w1200/2025/10/-------2025-10-26-------6.58.28-1-1.png)

**大家都說 AI可以增加生產力，那到底啥是真正的生產力？**

今早台北下大雨，我在家陽台跑了一小時的超慢跑，上面的圖是我的環境。這一小時裡，我同時做了四件事：

  1. 運動 : 超慢跑
  2. 知識擷取: 聽Youtube Video (AI Topic)
  3. Vibe Coding / 數據分析 : Claude Code
  4. 網頁搜尋資訊: ChatGPT Altas 

這個工作流之所以可行 ，因為「超慢跑 」+ 「Claude Code」 這個組合根本就是天作之合，超慢跑並非慢跑很安全，不需要太多注意力。 Claude Code 老實說真的在做事的時候，95% 的時間不需要去顧，但是總是有 5% 的需要出來 debug 一下，這時候超慢跑停下來一兩分鐘也沒差。

![](/assets/images/-------2025-10-26-------7.11.46-1.png)

我這樣的 routine 已經持續了3個月之久了，如果是出太陽的時候，​我就去我家的頂樓上超慢跑，可以看淡水河風景。除了剛剛的幾個工作流疊加以外，還能同時間曬太陽補充維他命D，順便讓自己壓力明顯的減緩，真的很有幫助。

當然，我那時候以為這就是多工的極限了

> 直到 Claude Code for Web 出現，他立刻解鎖了我新的多工/健康模式。

### 

### 通勤開車

當我在路上的時候，很多時候我會聽 YouTube or Podcast ，但是更多時候，我很想要知道最新的報表數字，進公司前做好準備。這個時候，Claude Code For Web 在手機上就可以做數據分析真的很好用! 我常常等紅燈，下指令下去，下一個紅燈停下來，結果就出來了。

眾所皆知，Claude Code 在數據分析上不只厲害，而且還可以根據你的要求快速的寫 python 幫你做更多的 deep dive ，根本就是AI For BI 數據分析的神器，沒有之一。

### 健身房

健身房我之前很少去，因為在那邊只能聽 Podcast ，還不如我的超慢跑+Claude Code 有效益。但是時間久了，大家都說無氧運動才是抗老化的另一個關鍵(真的），我就一直在尋思，我是不是要帶一台 Macbook Air 13去健身房放在 Hack Squat 機旁邊。還好，有了 Claude Code for Web，一切都解決了

![](/assets/images/ChatGPT-Image-2025---10---28----------09_19_18-1.png)

現在每做完一組動作，拿出手機看 Claude Code 跑得怎樣，有狀況再微調即可。我也不用當一個顯眼包。

### 走路

晚餐後，有些時候我會走走消消食，那個時候，我也會打開 ChatGPT Live Chat 討論一下一些思維跟議題， ChatGPT Live Chat 講話跟溝通很順暢，幫你上網查查資訊很方便，整理一些思維，走著走著就有靈感了。不過有了 Claude Code for Web ，除了 Live Chat 以外，我還會沒事順便看一下 code 寫到哪了，或是數據分析到哪了。

### 工作會議

另外一個 Claude Code 有效率的改變我的人生的，就是它可以幫助我在開大大小小的會議的時候，還可以空出 5% 左右的時間去持續產出 Code 以及做快速的資料分析。這些也是 Claude Code 對我人生中很有感的事情。

![](/assets/images/282d1b38-3df2-4eba-a405-571ee172c672-1-1-1.png)

### AI 有感的提升我的效率

這是一個經典的艾森豪矩陣，框架本身很清楚，區分重要，以及緊急。通常我們都會專注在「重要緊急」，忘掉「不重要也不緊急」的任務，但執行難點永遠在兩個地方

  * 「緊急但不重要」的事會源源不絕地來，傳統建議是委派給別人
  * 「重要但不緊急」的事才是真正的殺手。沒人會為它催你，所以最容易被挪到永遠的「待辦」名單裡。我的做法是強制定期檢視機制——不是靠意志力記得，而是系統化地固定看一遍，確保它們還活著。

![](/assets/images/image-49-1.png)

但是有了 AI ，我們的做法會有更多變化。

首先我們可以同時做「重要不緊急」以及「緊急不重要」的事情，像是我的運動 (重要不緊急）＋Claude Code幫我解一些bug (緊急不重要） ，也因為 Mobile Claude Code 的誕生，有感的增加我的健身房無氧訓練次數（幾乎是一週三次），這個也很明顯的增加生活質量。

在工作中，參與大量的會議(緊急但不一定重要)，也不會因此降低我的 Code Deliver 速度(重要)，我也重新變成一個可以參戰的 Engineer ，而非一個只能出一張嘴巴的管理者。這也增加我們團隊的生產力，因為很多時候，管理者挽起袖子下去做，會有效的增加更多對現場的感知，這對管理決策的判斷極為重要

**AI 的確增加了我的生產力，但不只是讓我做事速度變快。畢竟，真正的生產力，不是你的產量，而是你每天做了多少「真正重要的事」**
