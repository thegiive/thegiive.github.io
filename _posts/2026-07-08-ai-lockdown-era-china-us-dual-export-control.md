2026 年 6 月 12 日，Anthropic 發佈了 Fable 5。三天後，美國商務部下令封鎖，禁止外國人使用。

十八天後的 6 月 30 日，商務部長 Howard Lutnick 發函撤銷管制令。Anthropic 加裝了新的安全過濾器，7 月 1 日 Fable 5 全球恢復上線。

又過了六天，2026 年 7 月 7 日，Reuters 獨家報導：**中國商務部過去一個月密集召集 Alibaba、ByteDance、Z.ai 等科技巨頭，討論限制中國前沿 AI 模型的海外使用。**

兩場博弈，幾乎同時展開。

---

## 美國的博弈：封鎖、談判、解封

先說清楚美國這邊發生了什麼，因為這個過程本身就是一個教科書級的「政府管制 AI 模型」劇本。

### 時間線

| 日期 | 事件 |
|------|------|
| 6/12 | Anthropic 發佈 Fable 5 + Mythos 5 |
| 6/12 | Amazon 研究員發現繞過 Fable 5 安全措施的方法，可識別軟體漏洞 |
| 6/15 | 商務部下令封鎖，禁止外國人使用 Fable 5 和 Mythos 5 |
| 6/16 - 6/29 | Anthropic 與政府談判，訓練新安全過濾器（攔截率 >99%） |
| 6/30 | 商務部長 Lutnick 發函撤銷管制令 |
| 7/1 | Fable 5 + Mythos 5 全球恢復上線 |

### 博弈的三個關鍵細節

**第一，封鎖的真正原因不是「模型太強」，而是具體的安全漏洞。** Amazon 研究員發現了一種 prompt 方法可以繞過 Fable 5 的安全措施來識別軟體漏洞。但 Anthropic 反駁說，Opus 4.8、GPT-5.5、甚至 Kimi K2.7 都能識別同樣的漏洞——這不是 Fable 5 獨有的能力。

**第二，解封是有條件的。** Anthropic 承諾了三件事：主動偵測和處理安全風險、與政府合作制定未來模型的標準、向政府通報惡意使用行為。換句話說，Anthropic 用「自我監管」換回了「全球使用權」。

**第三，這建立了一個可重複的模式。** 政府可以隨時啟動管制→企業談判加安全措施→政府撤銷管制。這個「管制-談判-解封」的循環會成為常態。

我[之前寫 Fable 5 事件](https://ai-coding.wiselychen.com/fable-5-takedown-ai-export-control-precedent/)的時候，結論是「先例已經設下」。現在可以更精確地說：**不只是先例，而是一套完整的博弈機制已經成型。**

---

## 中國的博弈：正在建立規則

同一個月，中國這邊也在做類似的事，但節奏不同。

### 正在討論的架構

根據 Reuters 報導，商務部 + 國家發改委主導，提出三級管制架構：

- **第一級：基礎開源工具** → 簡單備案即可
- **第二級：進階技術** → 需要安全審查
- **第三級：前沿模型** → 禁止公開釋出或限制出境

除了模型管制，還有兩個配套：

- **AI 技術洩漏定性為國家安全罪** — 這比美國走得更遠。美國是出口管制（行政命令），中國直接拉到國安法層級。
- **收緊外資投資中國 AI 初創** — 2026 年 4 月 Meta 被令拆分 Manus 20 億美元收購案就是信號。

### 兩邊博弈的差異

| | 美國 | 中國 |
|---|---|---|
| **觸發機制** | 具體安全漏洞 → 快速反應 | 戰略判斷 → 制度設計 |
| **執行速度** | 18 天完成一輪（封鎖→解封） | 討論中，無確定時程 |
| **管制對象** | 單一模型（Fable/Mythos） | 全產業分級管制 |
| **法律層級** | 行政命令（可撤銷） | 國安法定性（更重） |
| **企業角色** | Anthropic 主動談判 | 企業被召集開會 |
| **開源態度** | 未涉及 | 明確納入管制範圍 |

最值得注意的差異是**開源**。美國這次管的是 Anthropic 的閉源模型，開源模型（Meta 的 Llama 系列）沒有受到影響。但中國討論的架構明確包含「更開放的版本」——也就是說，**中國的管制可能會影響到 DeepSeek、Qwen 這些全球廣泛使用的開源模型的未來版本釋出。**

## 從「開放出海」到「鎖國管制」的反轉

這件事最讓我在意的，是時間線上的反轉。

今年 2 月，我寫了[《Token 出海：中國 AI 不再賣商品，開始賣 Token》](https://ai-coding.wiselychen.com/china-token-export-new-trade-model-selling-intelligence/)。那時候的故事是 DeepSeek R1 席捲全球、GLM-5 全華為晶片訓練、中國模型 API 便宜 5-8 倍，Token 呼叫量首次超越美國。

五個月後，方向可能反轉。

不是說 Token 出海會完全停止——Reuters 報導裡的討論「無確定時程」，而且基礎開源工具仍然只需備案。但訊號已經非常明確：**當你的模型夠強，政府就會來管。不管是哪一邊的政府。**

Fable 5 的經驗告訴我們：管制不一定是永久的，但管制的機制一旦建立，就會反覆使用。

---

## 為什麼 AI 模型變成「國家戰略資產」

先進晶片被管制，大家早就習慣了。TSMC 的 3nm 製程、NVIDIA 的 H100/B200，都有出口管制。

但 AI 模型是軟體，軟體怎麼管？

答案是：**當軟體的能力達到某個門檻，它就不再是軟體了。**

具體來說：

1. **軍事與情報應用** — 前沿模型可以做自主網路攻擊、生物武器設計輔助、情報分析。Fable 5 被封鎖的直接原因就是軟體漏洞識別能力。

2. **經濟競爭力** — 一個國家的前沿模型被對手免費使用，等於把核心競爭力白送。中國商務部的邏輯在這裡。

3. **不可逆的能力擴散** — 晶片可以扣住不賣，但模型權重一旦外洩就收不回來。這是為什麼中國討論把 AI 洩漏定性為國安罪——比美國的行政命令層級更高。

用 @AYi_AInotes 的話說：**先進 AI 已經從普通軟體，升級成了和先進晶片同級的國家戰略資產。**

Fable 5 事件證明了這不是理論——Anthropic 用了 18 天才拿回全球使用權，代價是接受政府監管條件。

## 對企業的三個實務衝擊

### 1. 模型供應鏈的「斷供風險」從假設變成現實

Fable 5 被封鎖的那 18 天，全球依賴 Claude 最強模型的企業都受到影響。雖然最後解封了，但沒有人能保證下一次也會解封，更沒有人能保證解封的速度。

如果你的產品核心依賴某個中國模型的 API（DeepSeek、Qwen、GLM），同樣的問題現在也適用：如果這個 API 明天對海外用戶關閉，你的業務連續性計畫是什麼？

這不是「會不會發生」的問題——美國這邊已經發生過了，中國這邊正在討論中。

### 2. 開源不等於永遠可用

很多人以為用開源模型就安全了——權重都下載到本地了，誰管得著？

Reuters 報導裡有一個細節值得注意：中國討論的管制架構是**分級的**，包括「更開放的版本」（more open versions）。也就是說，未來中國的前沿開源模型可能在釋出前就被攔下來。

你已經下載的權重沒人能收回。但下一個版本可能不會再出現在 Hugging Face 上。

### 3. 「便宜 5 倍」的中國 API 可能消失

過去半年，很多企業——特別是東南亞、中東、歐洲的——選擇中國模型 API 的核心理由是成本。GLM-5 的 API 價格是 Opus 的五分之一。

如果中國對前沿模型實施出口管制，這個成本優勢可能一夜消失。不是漲價，是直接不可用。

## 加速投資地端的邏輯變了

我在五月寫[《On-Prem 小模型爆發時代來了》](https://ai-coding.wiselychen.com/on-prem-small-model-explosion-2026-shift/)的時候，投資地端的主要邏輯是：

- 開源小模型能力追上 Sonnet 級別
- RTX 5090 跑 27B 模型可以達到生產級吞吐
- 雲端 Token 越來越貴

那時候的框架是**成本優化**——算一算 ROI，高頻 workload 搬回地端比較划算。

現在邏輯升級了。

### 地端投資的三個新理由

**第一，業務連續性。** Fable 5 斷供 18 天是真實案例。不管你用美國還是中國的模型，都有被管制的可能。地端部署的模型不會被遠端關掉。

**第二，合規避險。** 當兩個超級大國同時把 AI 模型定義為戰略資產，中間地帶的企業（台灣、東南亞、歐洲）面臨的合規風險是雙向的。用美國模型可能踩中國的線，用中國模型可能踩美國的線。地端跑開源模型是唯一兩邊都不踩的選項。

**第三，供應商多元化。** 聰明的做法不是押注某一邊，而是建立「模型多源架構」——雲端 API 用最強的前沿模型處理高價值任務，地端用開源模型處理高頻日常任務。當某個雲端 API 斷供，地端可以接住。

### 已經可以做的事

如果你還沒開始投資地端，這是我目前對客戶的建議邏輯：

1. **盤點你的模型依賴** — 列出所有用到的 AI API，標注來源國。如果 80% 以上集中在同一個來源，你就有供應鏈風險。

2. **建立地端推論能力** — 一台 RTX 5090 桌機（約台幣 15-20 萬）跑 Qwen 3.6-27B，可以覆蓋大部分日常 workload。不需要一步到位，先把最高頻的任務搬過來。

3. **設計 fallback 機制** — 你的應用架構應該能在「雲端 API 不可用」時自動切換到地端模型。這不是過度設計，Fable 5 事件證明這是 2026 年的基本功。

4. **趁現在下載權重** — 目前 DeepSeek、Qwen、GLM 的開源權重都還在 Hugging Face 上。如果中國真的實施管制，未來的新版本可能就下不到了。

## 雙極生態已經成型

退一步看全局。

2025 年，AI 的故事還是「全球化」——DeepSeek R1 在全球爆紅，中國模型 API 服務全球客戶，大家用最好、最便宜的工具。

2026 年，故事變成「雙極化」——美國管制 Fable/Mythos（雖然後來解封），中國醞釀管制前沿模型出口，兩邊各自建立管制機制。

不同的是，美國的模式是「反應式」——出了安全問題再管，談判後可以放開。中國的模式是「制度式」——先設計好三級管制架構，從源頭管起。

歐洲怎麼辦？歐洲的前沿基礎模型只剩個位數，算力、資本、人才全方面落後，再加上 AI Act 的監管限制。但歐洲在工業垂直 AI、開源研究底蘊、全球監管標準的話語權上還有存量優勢。「可信 AI」的定位，在政企採購市場依然有商業價值。

台灣呢？台灣製造先進晶片，但不製造前沿模型。在雙極生態裡，台灣的位置其實比較尷尬——製造戰略資產的上游，但在應用端同時依賴兩邊的模型。地端部署，對台灣企業來說可能是最務實的避險策略。

---

## 總結

過去一個月發生的事情，可以用一句話概括：**中美兩個 AI 超級大國，用不同節奏做了同一件事——把前沿 AI 模型從商品重新定義為國家戰略資產。**

美國走完了一輪完整的「管制→談判→解封」循環，建立了可重複的博弈機制。中國正在設計更系統化的三級管制架構，還沒落地但方向明確。

對企業來說，不管最終結果如何，實務上的行動只有三件事：

1. **盤點模型供應鏈風險** — 你依賴誰的模型？如果斷供，你有 Plan B 嗎？
2. **加速投資地端** — 從「成本優化」升級為「業務連續性」，這是 2026 下半年最該花的錢
3. **趁開源模型還能下載，建立本地權重庫** — 這可能是有時效性的窗口

AI 無國界的時代，結束了。
