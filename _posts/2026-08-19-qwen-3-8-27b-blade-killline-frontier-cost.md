Artificial Analysis 這週在 Intelligence Index v4.1.1 上加了一個功能叫 kill sweep——你設定一個自架成本，它在圖上畫出一條線，所有比這條線更貴、智力又不比你高的模型，全部被一刀斬掉。

Qwen3.8-27B 自架在 RTX 5090 上，10% 利用率，那條線落在 $0.0143/task。

我稱它為斬殺線。

![Artificial Analysis Intelligence Index v4.1.1 vs Cost per Task](/assets/images/qwen-3-8-27b-blade-killline-cost.png)

---

## 這條線殺掉了什麼

137 個模型，16 個家族，2026-08-18 抓取的數據。Y 軸 Intelligence Index（9 項加權評測總分），X 軸每 task 美元成本，對數尺度。

黃色菱形就是 Qwen3.8-27B 自架。Intelligence Index 52 分。

GPT-5.6 Luna max 也是 52 分左右。但 task 成本在 $0.03 附近——是 Qwen3.8 自架的 2 倍多。再往右看同一條水平線：GPT-5.4 xhigh 大約 $1.5/task，Claude Opus 5 low 大約 $0.3/task。用自架 Qwen3.8-27B 跑同等智力的工作，成本是它們的 1/100 和 1/20。

斬殺線劃過去，圖上大半的 API 模型掉進死區——更貴、而且更笨或同等智力。上週寫過[這個模型的 benchmark 拆解](/qwen-3-8-27b-open-weights-local-security/)，agentic 任務贏 Opus、知識任務輸。今天不看分數，看成本。

---

## 斬殺線只會往左移，不會往右

這條線為什麼不是靜態的？因為雲端 API 和地端自架的成本結構完全不同。

**雲端 API 是邊際定價：** 每個 token 都收錢，每次 call 都計費。模型想得越久、生成越多，帳單越高。提供商可以隨時調價，volume discount 改善幅度有限。

**自架是固定攤提：** 硬體折舊 + 電費。跑一個 task 跟跑一千個 task，硬體成本一樣。Artificial Analysis 圖上那個 $0.0143 是用 RTX 5090 算、10% 利用率的數字。如果利用率拉到 50%，單位成本直接再除 5。

然後是授權費的問題。

Qwen3.8-27B 是 Apache 2.0。零。授權費是零。不是便宜，是零。你買了卡，剩下的成本就是電費。

這意味著：

1. **硬體越來越便宜** — 每一代 GPU 的 tokens/watt 都在提升
2. **社群優化不斷降低運算需求** — 相同品質需要更少的資源
3. **利用率越高越便宜** — 跑越多，均攤越低
4. **授權費永遠是零** — Apache 2.0 寫死的

四個力量全部往同一個方向推。斬殺線只會往左移。

換一個框架來看這件事：從租金變押金。

過去三年，你用最頂級的 AI 交的是租金。月費、API token、按量計費。一天不付，一天用不了。停訂閱那天，手裡什麼都不剩。

現在租金可以歸零。代價是一筆押金——一張 RTX 5090，8 月初台灣市場大概 17 萬。成本沒有消失，是從月底的帳單搬到了開機之前。但押金跟租金有一個本質差異：它是資產，不是費用。卡在你手上，能賣、能折舊、能等下一代出了再換。租金花掉就沒了。

Artificial Analysis 圖上還列了不同硬體的每日處理量：RTX 5090（293 tasks/day）、RTX 4090（147 tasks/day）、RTX 3090（73 tasks/day）、DGX Spark（22 tasks/day）。這些數字會隨推理引擎優化持續上升，進一步壓低單位成本。

## 社群飛輪：第一週就已經這樣了

Qwen3.8-27B 釋出不到一週，我整理了 [300+ 條 X 貼文的社群實測數據](/qwen-3-8-27b-all-platform-deployment-guide/)——RTX 3090 到 DGX Spark 六種硬體，tok/s 從 6 到 400 都有人喊。

那篇文章的結論只有一句話：太可怕的社群力量了。

量化方面，AtomicChat 的 AD（Adaptive Dynamic）格式在相同檔案大小下全面壓過 unsloth、lmstudio-community、ggml-org 的通用量化。24GB VRAM 用 AD-Q5_K 就能跑到 97.3% 的 Top-1 準確率，人類使用時幾乎感受不到跟全精度的差異。一張 RTX 4090 就夠了。

推理引擎也在同步加速：llama.cpp 的 MTP 支援讓 RTX 4090 從 45 飆到 97 tok/s，SGLang 在 5090 上跑出四人併發每人 106 tok/s。

而且這只是第一週。

回顧每個熱門開源模型的歷史軌跡，社群優化在前三個月最密集。每一層優化都讓同一張卡跑得更快，或者讓更便宜的卡跑得動。每一次優化，斬殺線都往左移一格。社群飛輪才剛開始轉。

## 27B 怎麼追到 frontier

52 分。一個 27B dense 模型，跟 GPT-5.6 Luna 同分。前代 Qwen3.6-27B 大概在 38 分的位置。一代之間跳了 14 個點。

怎麼做到的？

Artificial Analysis 的評測紀錄顯示，Qwen3.8-27B 在評測中總共生成了 1.6 億 tokens，而所有受測模型的中位數只有 4300 萬。接近 4 倍的推理量。

它在用更長的思維鏈、更多的搜索、更多的反覆驗證，來彌補參數量的不足。小模型靠「想得更用力」追平大模型。

這裡出現了一個結構性的經濟反轉。

在雲端，想得更用力 = 生成更多 token = 帳單更高。長思維鏈在 API 定價模型裡是成本放大器。

在本地，想得更用力 = 多花一點電和時間。Token 成本接近零。長思維鏈在自架模型裡是免費的智力放大器。

同一個機制——test-time compute——在兩種成本結構下產生完全相反的經濟效應。雲端越想越貴，本地越想越值。

這就是為什麼斬殺線不只是「便宜」這麼簡單。Qwen3.8-27B 的智力來源本身就偏向自架友好。它靠的不是堆參數（那需要更大的卡），而是靠推理時間換品質（那只需要更多的電和耐心）。

規模不再是唯一答案。智力密度比參數規模重要得多。27B 的參數密度能做到這個水平，靠的是高品質 Agent 軌跡後訓練加上混合注意力架構（48 層 Gated DeltaNet + 16 層 full attention）的創新。

### 智力密度比較：每 B 參數能換幾分？

把幾個前沿開源模型的 Intelligence Index 分數除以參數量，得到「分/B」——每十億參數能買到多少智力。數字越高，密度越高。

| Model | 總參數 | 每 token 激活 | Index | 分/總 B | 分/激活 B |
|-------|--------|-------------|-------|--------|----------|
| **Qwen3.8-27B** | 27B dense | 27B | 52 | **1.93** | 1.93 |
| DeepSeek V4 Flash 0731 | 284B MoE | 13B | 50 | 0.18 | **3.85** |
| GLM 5.3 | 743B MoE | 40B | 60 | 0.08 | 1.50 |
| Kimi K3 | 2,800B MoE | 104B | 60 | 0.02 | 0.58 |

**分/總 B** 決定你需要多少 VRAM。Qwen3.8-27B 是 1.93，Kimi K3 是 0.02——差 90 倍。每 GB 記憶體能買到的智力，27B dense 斷層第一。

**分/激活 B** 是算力效率。DeepSeek V4 Flash 最高 3.85，因為每 token 只叫醒 13B 參數。但 284B 的總參數還是要全塞進記憶體，本地消費級硬體跑不動。

對本地部署來說，分/總 B 才是唯一重要的數字。而 Qwen3.8-27B 在這個指標上，沒有對手。

## 清醒時間

斬殺線殺的是成本。不是所有維度。

**知識類評測偏弱。** 上一篇拆過[贏輸分布](/qwen-3-8-27b-open-weights-local-security/)：27B 贏的全是 agentic workflow 類項目（SWE-bench Pro、OSWorld、AndroidWorld），輸的全是知識天花板類（GPQA Diamond、HLE）。它更適合 Coding 和 Agent 場景，不是純知識問答的萬用模型。

**容易幻覺。** 27B 的知識密度終究比不上幾百 B 的大模型。事實性要求高的場景（法律、醫療、金融），還是需要大模型或 RAG 輔助。

**長 CoT 有延遲代價。** 1.6 億 tokens 的推理量意味著等待時間不短。一張 4090 跑完整思維鏈，某些 task 可能到分鐘級別。實際使用需要主動調 reasoning effort，不是每個 task 都要想這麼久。

**功耗和散熱是實務問題。** RTX 5090 滿載 575W。電費在台灣確實可以忽略不計（一天幾十塊），但散熱規劃和長時間運行的穩定性是另一回事。

不過——這些限制全部是已知的、可工程化處理的。知識弱就接 RAG，幻覺多就加驗證層，延遲高就調 reasoning effort，功耗大就用效率更好的量化。沒有一個是結構性的死穴。

## 杰文斯悖論：智力便宜之後會怎樣

1866 年，英國經濟學家杰文斯翻帳本發現一件所有人都猜反的事：蒸汽機越來越省煤，英國的煤消耗不是下降——是翻著倍往上漲。

道理不複雜。煤貴的時候，只有最賺錢的礦主用得起蒸汽機。煤一便宜，紡織廠用得起了，鐵路用得起了，輪船用得起了，最後連家裡燒熱水都用得起了。每一分省下來的成本都被新冒出來的用途吃回去——還不夠吃。

智力正在走同一條路。

今天頂級 AI 智力是奢侈品。$0.014/task 聽起來便宜，但 Frontier 級的雲端模型動輒 $0.3-$3/task，所以只有最高價值的任務才配用：寫程式、做研報、跑量化交易策略、自動化法律文件審查。一間十人新創每月光 API 帳單就可能燒掉一個工程師的薪水。絕大多數日常任務請不起 Sota 模型幫忙。

但當智力的單價從 $3 掉到 $0.014——降了 200 倍——被解鎖的不是「原來的任務變便宜」，是「一整層過去根本不值得用 AI 的任務突然變得合理」。你那份 200 頁的政府採購規格書要有人逐條比對、公司裡那套跑了十五年沒人敢重構的 legacy 系統要有人讀懂、客服團隊每天回覆的那三百封信要有人分類分派——這些事從來不缺方案，缺的是「值得為它花那個腦子」的經濟條件。

真正會閒下來的是按舊假設建的基礎設施。上面那張智力密度表說得很清楚：Kimi K3 拿 60 分要 2,800B 參數，分/總 B 只有 0.02。Qwen3.8-27B 拿 52 分只要 27B，分/總 B 是 1.93——差 90 倍。全世界囤的 IDC、卡、電站，是按「頂級智力 = 萬億參數 = 十一張卡拼起來跑」這個前提算出來的。現在一張卡就裝得下同等智力的 dense 模型，同一度電能榨出幾十倍有用的聰明。

杰文斯保證需求最後一定會漲上來填滿產能。杰文斯不保證的是時間差——需求漲上來的那一天，和那些帳單到期的那一天，哪個先到。

## 24GB 就是新的門檻

以前本地能跑和真正有用之間有一道巨大的鴻溝。本地模型跑得動，但品質差太多，用了比不用還痛苦。

Qwen3.8-27B 是第一次把這道溝填上了。

Intelligence Index 52 分——跟 GPT-5.6 Luna 同級。24GB 消費級顯卡用 AD-Q5_K 跑到 97.3% 準確率。每 task 成本 $0.014。Apache 2.0 零授權費。社群優化還在第一週。同一週 DeepSeek 開源了 DSH（harness 層），模型是嘴、harness 是手——嘴跟手第一次都歸你了。

這組數字放在一起，構成了一條只會往左移的斬殺線。

Cline 官方的原話：「我們完全沒預料到本地模型進步會這麼快。」

頂級智力今天的售價是一張 5090，17 萬。半年前同一個水平只在別人的機房裡，你出多少錢都只能遠端租用。六萬塊是現在的匯率。一年後多少？五年後多少？數字不敢報，但方向已經確定：價格往下走，跟 frontier 的差距往短裡走。總有一天它會便宜到你不再單獨為它付一筆錢——就像你今天不會每開一次燈專門算一次電費。

到那個時候，最值錢的不是聰明本身。是你拿聰明來幹什麼。

雲端閉源模型的護城河在轉移——從純智力，轉向基礎設施的穩定性、生態系的完整度、產品整合的深度。但純智力？純智力這條護城河，已經被 $0.01 一刀切開了。

本地 AI 不再是玩具。它第一次有資格站到真正的複雜工作流面前。
