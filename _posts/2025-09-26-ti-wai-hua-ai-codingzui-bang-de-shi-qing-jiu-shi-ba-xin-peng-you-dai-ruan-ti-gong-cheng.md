# VIBE Coding最棒的事情就是把新朋友帶軟體開發的世界




![VIBE  Coding最棒的事情就是把新朋友帶軟體開發的世界](/assets/images/OHUFc_3kQtKONOdt6oSbZ.png) Prompt : 工程師跟麻瓜手牽手

昨天看到 VIBE Coding / Google AI Studio 某篇文章瘋傳，看到社群朋友們給予相關的「指導」。心裡想說啥，又不知道要怎講。

回去看原 PO ，嘖嘖，是正妹。我就要指責大家了

> 「以前我們資工系人因為9:1 的男女比，巴不得把妹子當成寶，手把手教他們的優良包容傳統到哪去了 ....XD」

好啦，以上是很不 DEI 的發言，Google 人不要抓我進去 Say Something 。但是差不多是我的感覺。

Code 寫不好，教就是了我們不也是整天都commit security key 進git 嗎？還不是整天 GCP IAM 權限全開 Project Owner 嗎? 

### 理解彼此的長處

今年開始，因為商周的採訪關係，我受邀很多場子講 AI ，也有一些上市公司請我過去講 AI轉型的經驗，經過幾次摸爬滾打，我有兩次場子邀請了 [JLMS-珍妮的華語教學筆記 的 Jenny](https://www.jlmsjennylin.com/?ref=ai-coding.wiselychen.com) 跟我一起來講課，一開始Jenny 講個人生產力提升跟對個人工作的加速，我講最新技術發展跟數位轉型經驗，結果效果都很棒！！！

![](/assets/images/image-36.png)我跟 Jenny 三月在 ALP 的演講，有了 Jenny 幫忙很成功

因為 Jenny 就是口條的比我好，投影片製作精美，案例也很 solid 。我的風格已經太過嚴肅跟老氣...XD，但是有了 Jenny 前面的抓眼球並且從個人角度出發，我再用企業角度，適度傳播轉型經驗，不容易造成大家的審美疲勞，我反而可以輕鬆地把技術深度帶進來。上週五，在 Inside 場子，也是跟 Vivi 這樣類似的合作方式，我自己也覺得獲得很高的滿意度。

這些新朋友，像是 Jenny 是老師 ，教育教學這方面她就是專才呀。Vivi 行銷傳播上，就是比我們這些工程師強。這很明顯

> 更多人的加入，帶來了更多是更多的 DNA ，以及 make something better 的機會

至於 API Key ，人家已經被扣錢了，人家心情已經很差了 ，給點情緒價值吧....工程師暖男這時候，該做的事是教大家怎麼預防 best practice 比較好吧 .....

### 新世界的來臨

這個小事故就是一個社群現象的呈現，VIBE Coding 就是在一個新世界的 trigger point ，身為古老的工程師們，不管你喜歡就是不喜歡，大量的「新朋友」就是會進來跟你一起工作，不管你喜歡不喜歡，AI的確就是弭平了你之前 20年的積累的技術知識，我們就是會跟他們一起做工作。

> 可是我一點都不覺得這是壞事，只是要習慣

因為我們這些老工程師也獲利，我帶著非資訊科系的小朋友們一起做專案，我們公司的成本下降，產能說實在真的提升(我們需要相關 QA / Code Review 流程把關 like [ATPM](https://ai-coding.wiselychen.com/atpm-a-real-production-vibe-coding-process/) ) 。而且有了他們，我不害怕工程師鬧加薪離職，對我這個技術主管來說，AI帶給我幾乎都是好處，我有了這些任勞任怨並且很努力的這些小朋友們，是我的寶藏

### 犯錯是正常

只是這些新朋友們會不會犯可笑的錯誤，當然會。我還記得有一天我的艾立弟弟妹妹們問我

> 剛剛跟某 IT 開會，我搞砸了，請問 SQL Server 是啥？我只知道 BigQuery ....

![](/assets/images/image-37-1.png)Nano Banaba : 一個年輕人抓著頭問另一個工程師 "SQL Server是啥“

我聽完狀況，只說「下次多看 agenda ，提前問 AI查技術代表的意義，然後你們如果判斷下次需要我到場，你們就強迫我到會議」。

我打個電話跟那位 IT 道歉，說下次我一定會出席會議，避免你們覺得雞同鴨講。

> 那個 IT 說「沒事，小朋友們雖然菜逼八，但是不推事情，比其他團隊的老工程師好合作多了」

我道歉，是因為身為 Data&AI; Team 的主管，因為我派了一個還不 ready 的下屬去開跨部門會議，這是我的失職。

IT 可以生氣，但是他理解的原因是因為，他跟我合作很久了，比起嘲笑不知道 SQL Server 的小朋友，他知道「 _這些**小朋友真的在解決問題，而且他肉眼可見這些小朋友的熱情跟 hand-on 對倉庫營運現場帶來很大幫助」**_ 。

小朋友他們不理解一些基本 IT 知識，只是需要一點引導。或許我們更需要這位 IT的包容，互相理解彼此的不足，多看他們帶來的好處。

> 而且工程師犯的可笑錯還會少嗎？

我昨天一個客戶present ，把七個月說成十個月，但是馬上被大家拉回來了，沒被客戶罵。

而且他們結束還對我說，「Wisely，你的回答好完美，該怎麼像你一樣？」，嘖嘖，弟弟很會情緒價值拉滿。

### 人都是會成長的，麻瓜也是

昨天一直在忙新公司數個案子拆炸彈的事情，但是也有幾個很開心事情

  1. 某個大三跟我兩年的國貿大男孩，昨天在一個上千萬的專案提案，表現的非常有台風，並且前期技術準備工作做得很好
  2. 某個跟我一年多的行銷少女，本週在剛接了某兩個大案子的PM，昨天我沒空去看他，晚上看聊天群組，我發現她一個人按耐住著客戶解釋議題，並且多方釐清問題很到位

看到他們突然之間，從一個矇懂無知的小弟弟妹妹，變成可以一起作戰的戰友，滿滿的自豪。人都有菜的時候，但是麻瓜也會長成大南瓜

![](/assets/images/IMG_9870-2-1.jpg)我們真的就是一個老工程師+一堆麻瓜創造的團隊

我能做的就是站在他們背後，當犯了好笑的錯誤，偷偷拉到旁邊指導一下，然後繼續給他們拍拍手就好
