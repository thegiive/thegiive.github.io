# AWS 裁員 3萬人的背後意義 ：更加追逐算力而非人才




![AWS 裁員 3萬人的背後意義  ：更加追逐算力而非人才](/assets/images/-------2025-11-01-------10.44.47.png) 圖片來源: Flickr/Web Summit CC BY 2.0

我們都看到 AWS 近期內裁員 3萬人，但是最有趣的是，近期 AWS 財報不論是 Q2 , 或是 Q3，都有相當不錯的獲利，並且Q3也擊敗分析師預期。在這個情況下，AWS 依舊啟動這次 2020年以來最大的裁員。

> 是 AI Agent 真的要取代人了嗎？

其實事情也沒那麼複雜，大概率問題就是幾個

  1. 現實面就是 GPU 不夠賣了，所以 AWS 大舉增加資本支出，從原本的1,180億美元上修至1,250億美元，目標就是建更多的雲跟GPU 。(從財報看不出來 GPU 缺口多少，但是有一個側面數字 AWS Q2 backlog 1,950 億美元 , 年增率約 25%）
  2. 既然要盡快多買 GPU ，砍人省下來的錢買算力，這個做法比較像是預算移轉（人員 -> 算力）
  3. 經濟情勢看似蒸蒸日上，但是 AI Crash 論一直都懸在大家的頭上，裁員讓 Opex 少一點至少安全

最後一個陰謀論很有趣，當我們要降本增效的時候，通常做法有兩種

  1. 根據 workload ，算清楚需要多少人，然後裁掉適當的數量
  2. 直接抓瞎裁一個比例，如果公司沒倒，就是裁員成功。裁到大動脈，再把人少量的 hire 回來

這次AWS的數字有點多，比較像是 Option 2 ，但是不管怎麼做，裁員通常都會倒逼公司內部牛馬們增加資源利用率，提升效能。

所以一切都還是先看商業，不一定是 AI Agent 真的可以取代人。只是老闆會用 AI 當藉口裁員就是了

### SDE牛馬們, 我們該怎麼辦 : 對沖

一個簡單的邏輯「對沖」，購買整個算力供應鏈的無法避開的鏈條股票

  * 製造端: ASML, TSMC , Nvidia, AMD 
  * 雲端: AWS/GCP/Azure , NeoCloud 廠商
  * Application : 三大 LLM Model Provider 除了 Google 以外都沒上市, 但是可以去找持有 OpenAI / Antropic 最大的公司
